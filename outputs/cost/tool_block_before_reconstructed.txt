Name: get_claim
Signature: get_claim(case_id: str)
What: Retrieve the facts for one claim. This is the starting tool for every run.
Input: case_id must be one non-empty claim ID string.
Returns: ToolResult. On success, data contains exactly one claim with claim_id, member_id, hospital_id, date_of_service, narrative, complete documents, and complete lines. No full reference table is returned.
Fails when: INVALID_ARGUMENT, CLAIM_NOT_FOUND
Irreversible: False

Name: lookup_member
Signature: lookup_member(member_id: str)
What: Retrieve the policy link for one member.
Input: member_id must be one non-empty member ID string.
Returns: ToolResult. On success, data contains exactly one member with member_id and policy_id.
Fails when: INVALID_ARGUMENT, MEMBER_NOT_FOUND
Irreversible: False

Name: lookup_policy
Signature: lookup_policy(policy_id: str)
What: Retrieve policy status, dates, limits, and exclusions for one policy.
Input: policy_id must be one non-empty policy ID string.
Returns: ToolResult. On success, data contains exactly one policy with policy_id, product, status, start_date, end_date, annual_limit, used_to_date, remaining_limit, and the complete exclusions list.
Fails when: INVALID_ARGUMENT, POLICY_NOT_FOUND
Irreversible: False

Name: lookup_procedure
Signature: lookup_procedure(procedure_code: str)
What: Retrieve the reference facts for one procedure.
Input: procedure_code must be one non-empty procedure code string.
Returns: ToolResult. On success, data contains procedure_code, description, and requires_preauth for exactly one procedure.
Fails when: INVALID_ARGUMENT, PROCEDURE_NOT_FOUND
Irreversible: False

Name: check_coverage
Signature: check_coverage(member_id: str, procedure_code: str)
What: Check whether one procedure is excluded by the policy linked to one member.
Input: member_id and procedure_code must be non-empty strings.
Returns: ToolResult. On success, data contains procedure_code, excluded, and exclusion_rule.
Fails when: INVALID_ARGUMENT, NOT_FOUND
Irreversible: False

Name: check_required_documents
Signature: check_required_documents(procedure_code: str, attached_documents: list[str])
What: Check the required document for one procedure and whether it is attached.
Input: procedure_code must be a non-empty string; attached_documents must be the claim's complete document list.
Returns: ToolResult. On success, data contains procedure_code, required_document, and document_present.
Fails when: INVALID_ARGUMENT, PROCEDURE_NOT_FOUND
Irreversible: False

Name: get_preauthorisation
Signature: get_preauthorisation(member_id: str, procedure_code: str, date_of_service: str)
What: Return whether a relevant pre-authorisation exists and whether it is valid on the service date.
Input: member_id and procedure_code are non-empty strings; date_of_service uses YYYY-MM-DD.
Returns: ToolResult. On success, data is one fixed-shape object containing found, preauth_id, valid, valid_from, and valid_to. At most one relevant record is exposed. When the result supports a final decision, retain preauth_id, valid_from, and valid_to as explicit evidence rather than replacing them with only a tool call_id.
Fails when: INVALID_ARGUMENT, NOT_FOUND
Irreversible: False

Name: get_hospital_status
Signature: get_hospital_status(hospital_id: str)
What: Retrieve panel-network status for one hospital.
Input: hospital_id must be one non-empty hospital ID string.
Returns: ToolResult. On success, data contains exactly one hospital with hospital_id, name, panel, and country.
Fails when: INVALID_ARGUMENT, HOSPITAL_NOT_FOUND
Irreversible: False

Name: check_duplicate_claim
Signature: check_duplicate_claim(member_id: str, hospital_id: str, date_of_service: str, lines: list[dict])
What: Check whether member, hospital, service date, and the complete line-item set all match an earlier decided claim.
Input: member_id and hospital_id are non-empty strings; date_of_service uses YYYY-MM-DD; lines is the complete claim line list.
Returns: ToolResult. On success, data contains duplicate, prior_claim_id, and matched_fields. At most one prior_claim_id is returned.
Fails when: INVALID_ARGUMENT
Irreversible: False

Name: issue_decision_letter
Signature: issue_decision_letter(case_id: str, decision_record: FinalDecision, autonomy: str)
What: Append at most one gated decision record to a local JSONL file. It does not contact a real member or insurance system.
Input: case_id is non-empty; decision_record follows FinalDecision; autonomy is supplied and enforced by the trusted runtime.
Returns: ToolResult. Data contains logged, log_id, and gate_result. AUTONOMY_BLOCKED, CONFIRMATION_REQUIRED, FACTS_INCOMPLETE, and RUN_ID_REQUIRED are safe non-writing outcomes.
Fails when: INVALID_ARGUMENT
Irreversible: True
